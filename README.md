# Ride & Conquer

Conquête de territoire à vélo.

- `index.html` : l'application (comptes, carte OpenTopoMap, import GPX, clubs, classements), branchée sur Supabase
- `connexions.html`, `plan.html` : maquette de connexion des compteurs et plan des connecteurs (COROS, Garmin, Wahoo, Hammerhead)

Données : tables `rc_*` du projet Supabase `coach-miguel` (schéma additif, RLS activée).
Fond de carte : © contributeurs OpenStreetMap, SRTM | rendu © OpenTopoMap (CC-BY-SA).
