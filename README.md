# Ride & Conquer

Maquette web (style « Trail ») d'une app de conquête de territoire à vélo.

- `index.html` : carte (Solo / Club)
- `connexions.html` : connecter son compteur (COROS, Garmin, Wahoo, Hammerhead)
- `plan.html` : plan technique des connecteurs

Pages statiques, sans dépendance. Publiées avec GitHub Pages.
