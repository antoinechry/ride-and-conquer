# Ride & Conquer

Conquête de territoire à vélo.

- `index.html` : l'application (comptes, carte Esri World Topo, import GPX, clubs, classements), branchée sur Supabase

Données : tables `rc_*` du projet Supabase `coach-miguel` (schéma additif, RLS activée).
Fond de carte : Esri World Topo (tuiles © Esri, HERE, Garmin, FAO, NOAA, USGS, © contributeurs OpenStreetMap).
